# Спринт 33. Теки і спільний доступ до документів

> Заглушка. План пишеться перед стартом спринту; рішення вже ухвалені у [питаннях спринту 32](../32-documents-storage/planning-questions.md), розділи 0, 1, 2, 5, 13.

Теки як сутність (створити, назвати, вкласти, перенести документи) — переїхали сюди зі спринту 32 (2026-09-03), бо той і без них перевантажений, а єдине групування, потрібне на етапі сховища, вже виражене позначкою отримувача. Поверх тек — спільна робота: три рівні прав (дивитись, скачати, видалити), бейдж прав біля назви теки, один документ одночасно в кількох теках, протокол вступу новачка і зміни прав за згодою всіх учасників теки, вихід учасника без чиєїсь згоди. Класти документи в теку може лише їхній господар; людина без документної підписки повноцінно користується наданими правами, але завантажувати не може, бо це зробило б її господарем і зайняло б її місце.
