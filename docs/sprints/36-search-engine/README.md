# Спринт 36. Пошуковий двигун

> Заглушка. План пишеться перед стартом спринту; рамка — [архітектура епіку](../26-documents-architecture/README.md), § Пошук.

Індекси повнотексту і векторів у тій самій базі, нормалізація української при індексації (без морфології, її бере на себе семантика), векторизація фрагментів канонічних копій, запити з ізоляцією по отримувачах виключно з guard-резолву. Першим кроком спринту — окремий кластер бази під розробку і чекліст ручної перевірки у `docs/manual-checks/`: обидва рівні свідомо лишаються поза автотестами.

**Передумова:** спринт 35 (кабінет документів).
