# Спринт 34. AI-конвеєр обробки документів

> Заглушка. План пишеться перед стартом спринту; рамка — [архітектура епіку](../26-documents-architecture/README.md), § Конвеєр обробки.

Масовий закид файлів з розкладкою купи по папках (екран підтвердження розкладки і ручне доведення нерозібраного), черга фонової обробки, канонічна «ідеальна копія» вмісту, визначення типу, витяг полів і тегів з чанкуванням словника, впевненість по кожному результату, оцінка вартості з резервом кредитів і станом «чекає кредитів», списання за фактичною собівартістю, прогрес партій, режим «без обробки».

Сюди ж (2026-09-05, рішення при ревʼю спринту 32) **зміна складу файлів у вже створеному документі**: докласти або прибрати окремий файл. У спринті 32 склад фіксується при створенні, а кошик спроєктований лише для документів цілком; тут зміна складу потрібна по суті (скидає «перевірено людиною» і жене переобробку), і разом з нею кошик свідомо розширюється на окремі файли — куди йде прибраний файл і як повертається у свій документ.

**Передумова:** спринт 33 (теки і спільний доступ до документів).
