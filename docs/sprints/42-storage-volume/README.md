# Спринт 42. Докупівля обсягу сховища

> Заглушка. План пишеться перед стартом спринту. Заведено 2026-09-03 при плануванні спринту 32; за порядком виконання місце — після кабінету документів (спринт 36), номер не означає черговість.

У спринті 32 ліміт сховища жорсткий: 5 ГБ на акаунт, на межі завантаження просто зупиняються. Цей спринт відкриває обсяг понад базу.

**Що мусить вирішити план:**

- Що означає розмір документного пакета: скільки отримувачів людина веде, чи він же множить обсяг сховища. Питання свідомо лишене відкритим у спринті 32 (див. [§0 його питань](../32-documents-storage/planning-questions.md)).
- Чи діє формула «5 ГБ × розмір пакета», яка вже лежить у тарифній сітці (`billing.config.ts`) і віддається публічним каталогом, чи вона замінюється іншою. До цього спринту вона не діє.
- Механіка плати за перевищення: щомісячна рента кредитами за гігабайти понад базу (`storageRentCreditsPerGb` у сітці вже є, але нічим не нараховується), грейс-вікно при нестачі кредитів, стан «несплачена рента» і що він зупиняє. Архітектура епіку (спринт 26) описує це як чинне правило — воно чинним стає саме тут.
- Стеля перевищення: чи існує межа, за якою завантаження зупиняються попри готовність платити.
