# Спринт 34. Словник тегів

> Заглушка. План пишеться перед стартом спринту; рамка — [архітектура епіку](../26-documents-architecture/README.md), § Архітектурні рішення.

Глобальний курований словник як типізований конфіг у репозиторії, увімкнена підмножина на рівні отримувача, пропозиції нових тегів від AI і від людей, звʼязок «тип документа визначає релевантні теги».
